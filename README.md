# Ariel 的 HTML 工具箱 🌺

這裡放置各種實用的 HTML 工具，可以直接在瀏覽器中使用。

## 工具列表

### 🇰🇷 韓文40音家族圖
- **檔案:** `korean-alphabet-chart.html`
- **功能:** 互動式韓文字母學習
- **特色:** 
  - 點擊字母聽發音（Web Speech API）
  - 顏色分類（基礎音/送氣音/緊音）
  - 家族系統記憶法
  - 4週學習計劃

### 🔐 拼音→韓文轉換器
- **檔案:** `korean-pinyin-converter.html`
- **功能:** 中文拼音視覺加密
- **特色:**
  - 200+ 拼音組合對照
  - 即時轉換
  - 一鍵複製
  - 手機友善

## 使用方式

### 線上使用（GitHub Pages）
```
https://areilsakura-dev.github.io/ariel-workspace/tools/
```

### 本地使用
1. 下載 HTML 檔案
2. 用瀏覽器開啟
3. 無需網路連線

所有工具都是純前端 HTML + CSS + JavaScript，不需要後端伺服器。
